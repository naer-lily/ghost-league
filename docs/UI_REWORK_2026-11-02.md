## C. 下注模型

### C1 周注 / 日注（宿敌注）

- [x] **C1.1 下注拆成两部分**：
  1. **我比宿敌高多少 XP**（目标差值，数字越大越难）；
  2. **押多少钻石**。
- [x] **C1.2 目标差值不能写死**：根据双方战力/近期 XP 动态计算可选档位或范围；具体数值平衡由实现侧判断。
- [x] **C1.3 赔率随目标差值变化**：目标越高、达成越难，赔率越高；赔率在锁注时固定。
- [x] **C1.4 押注额支持 0–500 钻石动态输入**，不再只有 20/40/60。
- [x] **C1.5 保留每笔 20 免费本金**：押 0 时只用免费 20；押 N>20 时自付 N-20；赢按整注结算；输只失去自付部分。
- [x] **C1.6 周注**：押本周最终 XP 高于宿敌多少；周一 23:59 截止；下周一结算。
- [x] **C1.7 日注**：押今天 XP 高于宿敌多少；21:00 截止、22:30 结算；每天一次。
- [x] **C1.8 结算**：目标差值达成才赢；未达成输；平局/边界按 0 差处理，规则写清楚。

### C2 组注（组内排名注）

- [x] **C2.1 组注和宿敌注分开**：周注/日注是关于宿敌；组注是关于“我在本组本周 XP 排名”。
- [x] **C2.2 组注描述纠正**：不是“我们组进前三”，而是“我本人在本组本周排名进前三”。
- [x] **C2.3 组注独立位置**：不要和周注/日注混在同一个宿敌下注 dialog；放在小组榜/组注区域。
- [x] **C2.4 组注规则**：押我本周组内排名进前三；可配置名次档位（如前 1/前 3），赔率按难度；押注额 0–500；免费 20 规则同上；周一截止、下周一结算。
