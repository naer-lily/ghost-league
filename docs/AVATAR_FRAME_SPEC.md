# 头像框规格

这份文档定义 PWA 头像和 SVG 状态卡共用的头像框尺寸。新增边框、改样式或改状态卡时，都按这里的同一组数字执行。

## 唯一的尺寸口径

以头像直径 `D` 为基准：

| 项目 | 尺寸 | 说明 |
| --- | --- | --- |
| 头像直径 | `1.00D` | 头像图片本身的圆形直径 |
| 框体画布外径 | `1.36D` | 边框美术的完整正方形画布 |
| 框体内圈开孔 | `1.00D` | 中心透明圆，头像正好嵌进去 |
| 框体可见部分 | 开孔外到画布边缘 | 只显示 `1.00D` 到 `1.36D` 之间的一圈 |
| 辉光直径 | `1.08 × 1.36D = 1.4688D` | 辉光以框体画布为基准继续放大 |

画布比例固定为：

```text
框体画布 / 头像 = 1.36
开孔 / 头像 = 1.00
辉光 / 框体画布 = 1.08
```

层序从下到上：

```text
头像图片
  → 辉光（开孔内遮掉）
  → 边框美术（最上层，开孔内遮掉）
```

边框 overlay 和辉光都必须 `pointer-events: none`，不能拦截头像、header 或小组行的点击。

## PWA 实现

PWA 的通用样式在 `web/style.css`，所有 frame id 共用同一套规则，不按单张素材另外缩放。

- 边框图片：宽高 `136%`，居中，`object-fit: contain`。
- 辉光：宽高 `146.88%`，颜色随边框，中心透明度 `0.34`，向外衰减。
- 开孔遮罩：边框图片中心透明到 `36.76%`，`36.77%` 之后显示。这个百分比来自 `0.5 / 1.36`，即开孔半径占框体画布宽度的比例。
- 余烬边框的外缘 alpha 已经烘焙进 PNG：从画布半径 `72%` 开始平滑衰减，到 `100%` 时严格为 0；CSS 不再给余烬加外缘径向遮罩，也不使用 `::before` 圆形辉光，避免出现另一圈硬边。
- 辉光同样遮掉中心开孔，避免橙色辉光糊在脸上；辉光开孔透明到 `34.04%`，`34.05%` 之后显示。这个百分比来自 `0.5 / 1.4688`。余烬的 `::before` 圆形辉光关闭，柔和光晕由素材 alpha 和 `filter: drop-shadow` 提供。
- 遮罩同时写 `mask-image` 和 `-webkit-mask-image`，并设置 `mask-size` / `-webkit-mask-size: 141.42% 141.42%`、居中、不重复。这样径向渐变的半径等于框体画布宽度，`36.76%` / `34.04%` 才对应实际像素半径，而不是默认的“到角落”半径。
- 头像图片仍用 `border-radius: 50%` 做圆形裁切；激活边框时容器 `overflow: visible`，只让框体和辉光溢出容器，不改变头像图片的圆形裁切。
- **边框槽不等于圆环**：`frame_clown` 是帽子型边框，素材是 AI 生图的透明背景帽子，只出现在头像上方，没有圆环。PWA 对它关闭中心开孔遮罩、圆环辉光和头像容器边框，SVG badge 的 `FrameVisual.glow_color=None` 关闭环状辉光。帽子在头像上按 `110%` 高度缩放，桌面上以头像顶部为锚点；小组榜的紧凑行降到 `90%`，header 不显示帽子，避免遮住标题或上一行。

## SVG 状态卡

`ghost_league/badge.py` 使用同一组比例：

```text
frame_size = icon_size × 1.36
glow_radius = frame_size / 2 × 1.08
```

对应常量是 `FRAME_CANVAS_SCALE = 1.36` 和 `FRAME_GLOW_SCALE = 1.08`。状态卡只统一比例，不引入另一套边框视觉。中心仍由透明的 `1.00D` 开孔对齐段位图标。

## 素材归一化

每个边框素材必须是一张正方形 PNG：

- 画布外径就是 `1.36D`，不要把素材自带的留白再算一次缩放。
- 中心透明开孔直径是 `1.00D`，开孔必须居中。
- 可见装饰只放在开孔以外到画布边缘之间；不要用素材自身留白来“微调”大小。
- 不要因为某张素材看起来偏大或偏小，单独改 `width` / `height` / `background-size`。需要修的是素材本身或规范，不是每个 frame 的 CSS。

## 新增边框检查清单

1. 素材是 `1.36D` 画布，中心是 `1.00D` 透明开孔，没有额外留白缩放。
2. 在 PWA 的 frame 资源表和 SVG 的 `FRAME_VISUALS` 里登记同一个 frame id。
3. PWA 继续使用通用 `136%` / `146.88%` 和开孔遮罩；帽子型 frame 例外：只关闭中心开孔遮罩、圆形辉光和容器边框，帽子按 `110%` 高度放在头像上方，小组榜行内缩到 `90%`。不改变其他 frame 的通用尺寸。
4. SVG 继续走 `icon_size × 1.36`；帽子型 frame 用 `hat_only` 走 `1.5 × icon_size` 独立布局，不生成圆环或圆形辉光。
5. 在 390 和 1440 宽度检查首页、个人页、header、小组榜自己的行、用户详情：
   - 开孔直径等于头像直径，脸不被框压住；
   - 框体外径 / 头像直径 = `1.36 ± 0.01`；
   - 辉光 / 框体画布 = `1.08 ± 0.01`；
   - 框体和辉光不被父级裁切，不遮姓名/分数，不产生横向滚动；
   - overlay 不拦截 header、头像和小组行点击。
6. 至少用两个不同 frame id 的 fixture 验证同尺寸、同开孔；不能只验余烬。
7. 无边框账号必须没有 overlay、没有辉光、没有破图。

相关文件：

- `web/style.css`：PWA 头像、开孔遮罩和辉光。
- `web/app.js`：`paintAvatarFrame` / frame id 接入范围。
- `ghost_league/badge.py`：SVG 状态卡 frame 尺寸与辉光半径。
- `web/sw.js`、`web/index.html`：改动 PWA 样式后同步升级缓存版本。
