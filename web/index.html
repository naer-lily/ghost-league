            集成文档

            用 Bearer token 记录活动进度，并读取自己的状态与榜单。

            开始之前

            认证

            Bearer

            所有 /v1/me/* 请求都使用请求头：

            Authorization: Bearer $GHOST_LEAGUE_TOKEN

            在这里查看或生成你的个人访问令牌。令牌只保存在当前设备；生成新令牌后，旧令牌会立即失效，请同步更新其他客户端。

            不要把完整令牌写入代码、日志或公开仓库。客户端可从 GHOST_LEAGUE_TOKEN 环境变量读取。

            写入

            记录进度

            POST

            POST /v1/me/increments 接收焦点时长增量。请求体示例：

            {
  "event_id": "unique-event-id",
  "seconds": 137
}
            • event_id 是幂等键：同一事件重复发送不会重复累计。
            • seconds 为正整数，没有 180 秒上限；客户端可按自己的节奏批量或增量发送。
            • 活动标签在个人资料页配置，服务端只存专注时长；第一版不处理距离、配速或组数。

            curl

            curl -X POST "https://your-host.example/v1/me/increments" \
  -H "Authorization: Bearer $GHOST_LEAGUE_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"event_id":"unique-event-id","seconds":137}'

            Python

            import os
import requests

base_url = "https://your-host.example"
headers = {"Authorization": f"Bearer {os.environ['GHOST_LEAGUE_TOKEN']}"}
payload = {"event_id": "unique-event-id", "seconds": 137}
response = requests.post(
    f"{base_url}/v1/me/increments",
    headers=headers,
    json=payload,
    timeout=10,
)
response.raise_for_status()
print(response.json())

            JavaScript

            const token = localStorage.getItem("gl.token.v1");
const baseUrl = window.location.origin;

async function recordIncrement(eventId, seconds) {
  const response = await fetch(`${baseUrl}/v1/me/increments`, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ event_id: eventId, seconds }),
  });
  if (!response.ok) throw new Error(`request failed: ${response.status}`);
  return response.json();
}

            可靠性

            先入队，再重试

            网络失败时不要丢掉事件。先把事件写入本地持久队列，再按顺序发送；重试必须复用同一个 event_id，服务端会去重。发送成功后从队列删除，失败则保留并退避重试。日志里只记录事件 ID 和状态，不要打印完整令牌或请求头。

            // 简化示例：队列持久化在 localStorage，event_id 在入队时生成一次。
const QUEUE_KEY = "gl.increment.queue.v1";

function enqueue(seconds) {
  const queue = JSON.parse(localStorage.getItem(QUEUE_KEY) || "[]");
  queue.push({
    event_id: crypto.randomUUID(),
    seconds,
  });
  localStorage.setItem(QUEUE_KEY, JSON.stringify(queue));
}

async function flush(token) {
  const queue = JSON.parse(localStorage.getItem(QUEUE_KEY) || "[]");
  while (queue.length) {
    const event = queue[0];
    const response = await fetch("/v1/me/increments", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${token}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify(event),
    });
    if (!response.ok) throw new Error("will retry the same event_id");
    queue.shift();
    localStorage.setItem(QUEUE_KEY, JSON.stringify(queue));
  }
}

            读取

            常用接口

            GET
            GET /v1/me/status

            今日 XP、100 XP 打卡状态、本周 XP、段位、小组名次、连胜和余烬余额。

            GET /v1/me/league

            我的小组、当前名次和本周 XP；成员按 XP 排名。

            GET /v1/league/standings

            当前小组的 15 人榜单，包含 name、XP、排名、今日打卡和连胜。

            GET /v1/league/history

            已结算周的结果列表；未结算时返回空的 results。

            GET /v1/me/embers

            余烬余额、上限、本周已赚和 ledger 明细。

            POST /v1/me/repair

            消耗 1 枚余烬补签最近的有效日期，需要 date 与 idempotency_key。

            GET /v1/me/checkins?week_start=

            按周查询每日打卡状态、XP 与来源。

            GET /v1/me/friends/standings

            跨段位好友榜。

            轮询状态

            curl -sS "https://your-host.example/v1/me/status" \
  -H "Authorization: Bearer $GHOST_LEAGUE_TOKEN"

            响应字段与状态码：缺失或错误令牌返回 401；请求体不合法返回 422。所有响应均为同源 JSON，不需要通配 CORS。
