# Tier icon assets

- Root `*.png`: the original 1024×1024 classic tier icons. Keep these files unchanged.
- `card/*.png`: the original card-sized classic icons used by the public SVG badge.
- `material/*.png`: Material-style transparent tier icons for the web tier rail,
  cropped to the alpha bbox and padded to a square canvas.
- `card/material/*.png`: Material-style transparent tier icons for the public
  SVG badge, cropped and padded with the same rule.

The Material-style files were generated by the image-generation workflow and
had their backgrounds removed. Their transparent margins were then trimmed to
the alpha bounds and each mark was centred on a square canvas with a 4% safety
margin, measured from the bbox short side. Both themes expose the same ten tier slugs so the theme registry can fall
back from `material` to `classic` when an individual asset is unavailable.
